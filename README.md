# Banat — Povestea locului dintre lumi

Website cultural interactiv realizat pentru evenimentul educațional **„România din clasă în clasă”**.

## Pornire locală

```bash
npm install
npm run dev
```

Pentru build de producție:

```bash
npm run build
npm run preview
```

Aplicația folosește React + TypeScript + Vite, Framer Motion, Leaflet și Lucide React. Progresul pașaportului digital este păstrat în `localStorage`, fără backend.
